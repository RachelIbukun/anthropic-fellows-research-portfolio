# Open Research Questions

## AI Security

1. What types of security vulnerabilities are most commonly introduced by AI assisted coding tools?

2. Do AI generated infrastructure configurations introduce different risks from AI-generated application code?

3. Are existing static analysis and security scanning tools sufficient to detect AI-generated security weaknesses?

4. How should organisations adapt DevSecOps practices for AI-assisted development workflows?

## Frontier Model Evaluation

1. How should frontier models be evaluated when used in software engineering and security sensitive workflows?

2. Can models that perform well on general coding benchmarks still introduce unacceptable security risks?

3. What types of adversarial prompts reveal unsafe or unreliable behaviour in AI assisted development?

## Economics & Policy

1. How should organisations measure productivity gains against security costs?

2. Does AI assisted development create hidden security debt?

3. What are the long term effects of AI assisted development on engineering expertise?

4. How should policymakers think about AI tools used in security sensitive software development?

## Governance

1. What level of human review should be required for AI generated code before deployment?

2. Who is accountable when AI generated code introduces vulnerabilities?

3. What audit trails should organisations maintain when using AI assisted software development tools?

4. How should organisations define acceptable risk thresholds for AI generated outputs?
