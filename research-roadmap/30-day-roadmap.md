# 30-Day Research Roadmap

## Research Theme

Evaluating security risks in AI assisted software development pipelines, with a focus on how frontier AI systems affect software security, developer productivity, governance, and organisational resilience.

## Week 1 — Research Foundation

### Goals

- Finalise the research question.
- Review relevant papers on AI-assisted development, skill formation, frontier model evaluation, and AI governance.
- Define the security and productivity metrics to be used in the project.

### Outputs

- Literature review notes
- Initial research questions
- Draft evaluation criteria
- Initial benchmark task categories

## Week 2 — Benchmark Design

### Goals

- Design realistic software development tasks for evaluation.
- Create task categories across Python, Terraform, CI/CD, Kubernetes, and dependency management.
- Define expected secure outputs for each task.

### Outputs

- Benchmark task list
- Security scoring framework
- Productivity measurement framework
- Initial evaluation template

## Week 3 — Pilot Evaluation

### Goals

- Run a small pilot using selected AI-assisted development tasks.
- Evaluate outputs for security weaknesses, insecure defaults, and governance concerns.
- Compare productivity benefits against security risks.

### Outputs

- Pilot results
- Initial vulnerability taxonomy
- Productivity versus risk analysis
- Lessons learned

## Week 4 — Research Write-Up

### Goals

- Produce a structured research briefing.
- Summarise findings, limitations, and future work.
- Identify policy and governance implications.

### Outputs

- Research briefing
- Governance recommendations
- Future research directions
- Public-facing project summary

## Success Criteria

By the end of 30 days, this project should produce:

- A clear research question
- A benchmark task set
- An initial evaluation framework
- A security risk taxonomy
- A short research briefing
- A roadmap for deeper empirical work
